# 《骑士异闻录》首页交互原型（已停用）

> **此 HTML 原型已停用**：首页开发已全面转入 Unity 工程（`unity/KnightChronicles/`），后续迭代以 Unity 的 `Lobby` 场景为准，本目录仅留档对照 FR-1102 的历史验收，不再更新。

这是对 SRS `FR-1102` 的可交互浏览器原型；它用于在 Unity 工程创建前完成首页视觉与交互验收，不替代最终的 Unity `Lobby` 场景实现。

## 打开方式

在项目根目录执行：

```sh
python3 -m http.server 4173 --directory prototype/homepage
```

然后打开 `http://localhost:4173`。

## 已覆盖的首页行为

- 同屏展示档案摘要、宝石、角色展示、最近战绩和全部一级入口。
- `activeRun` 存在时显示“继续游戏”，并置于第一个默认焦点；否则默认焦点为“开始远征”。
- 有未完成远征时，开始新远征会显示默认选择“取消”的危险确认弹窗。
- 退出游戏使用二次确认弹窗；原型中不实际关闭浏览器。
- 通过方向键和 Enter 可完成菜单操作；支持按钮焦点循环。
- 提供右下角低显著性开发状态开关，用于验收安全点、战绩读取骨架屏、存档失败重试状态。
- 布局在 1920×1080、1280×720 和窄屏下均会自适应。

## 与最终 Unity 页的迁移边界

- `app.js` 中的演示状态将替换为存档服务、页面路由和异步场景加载。
- 角色的 CSS 展示将替换为实时 3D 角色预览或高精度立绘。
- 首页背景已接入 `assets/ui/home-art/home_hall_background_cartoon_topdown_v2.png`。该版本是俯视角 3D 卡通化视觉；如果该文件缺失，当前 CSS 仍会自动降级到内置氛围背景。
