# 《骑士异闻录》首页美术规格 v1

## 1. 适用范围

本规格仅覆盖 `Lobby` 场景中的开始页面（FR-1102）。主视觉对应 `home_hall_background_v1.png`；它是静态环境底图，UI、角色实时模型、数值、按钮、Logo 和动态装饰均由 Unity 侧叠加，不烘焙进背景。

该图仅含环境，不含可读文字、Logo、按钮、角色、武器或 UI 图标，避免文字误识别并支持后续本地化。

## 3. 视觉方向

### 风格

- 原创低多边形 3D 奇幻大厅，采用 Toon Shading 的明暗分区与柔和边缘。
- 以“可读性优先的冒险者大厅”为核心：深色石材和木材为基底，暖色火焰与冷色月光建立层次。
- 氛围是“安静、可靠、即将远征”，避免恐怖、血腥、写实照片感或过量特效。
- 角色和武器保持主视觉主体；背景只承担空间、情绪与装饰功能。

## 4. 布局与安全区

设计基准为 **1920 × 1080**，遵循 SRS P-1。实际背景可按“覆盖填充（Cover）”缩放，但 UI 必须独立锚定，不能依赖背景中的具体像素位置。

| 区域 | 基准坐标 / 比例 | 视觉用途 | 接入约束 |
| --- | --- | --- |
| 全局安全区 | 四边各 5% | 核心 UI 不可越界区域 | 1920×1080 下为 X=96–1824，Y=54–1026 |
| 左侧角色展示区 | X=96–864，约 45% 宽 | 角色实时模型、待机动作、初始武器、角色名与定位 | 使用前景模型层；脚底对齐展示台中心附近；不可用纯白大面积遮挡月光与展示台 |
| 右侧菜单区 | X=1056–1728，约 35% 宽，Y=230–720 | 继续游戏 / 开始远征等 6–7 个垂直入口 | 保持背景右侧的暗色留白；按钮背景建议为 65–80% 不透明深蓝层 |
| 右下战绩区 | X=1220–1728，Y=760–970 | 最近一局战绩卡 / 新档提示 | 使用深色半透明卡，避免覆盖中央拱门与火焰焦点 |
| 顶栏左 | X=96–520，Y=54–120 | 游戏时长、总局数 | 小字号、弱层级，不抢主菜单焦点 |
| 顶栏右 | X=1450–1824，Y=54–120 | 宝石余额、版本号 | 宝石图标优先使用远征金，数值为主文字色 |

在 21:9 时保持中心画面不缩小，新增宽度用于背景延展；菜单和角色区仍以 1920×1080 的安全区定位。1280×720 下，按钮文字不换行，优先缩小卡片留白而非缩小正文到不可读。

## 5. UI 与动态层建议

### 叠加顺序（后 → 前）

1. `HomeHallBackground`：本静态背景。
2. `AtmosphereFX`：低密度尘埃、烛火、微弱奥术粒子；仅装饰，不进入菜单文本区域。
3. `CharacterShowcase`：实时角色模型、武器和地面接触阴影。
4. `UIShade`：右侧菜单 25–35% 深蓝渐变遮罩；必要时加强到保证 4.5:1 对比度。
5. `HomeMenuUI`：Logo、档案摘要、宝石、菜单按钮、战绩卡。
6. `FocusAndModal`：键盘焦点框、红点、Toast、确认弹窗与全屏模态暗角。

### 状态反馈

| 状态 | 视觉建议 |
| --- | --- |
| 默认按钮 | 深蓝半透明底 + 1 px 炭灰边框；文字 `#F4F7FB` |
| 鼠标悬停 | 背景略提亮，远征金或奥术青细描边；不改变左侧角色展示 |
| 键盘焦点 | 2 px 奥术青外描边 + 轻微呼吸发光，不能只依赖颜色，保留形状描边 |
| 主动作（开始远征/继续游戏） | 使用远征金与奥术青双层强调；继续游戏出现时优先获得默认焦点 |
| 不可用 | 降低不透明度并保留可读说明；不可只靠灰色区分 |
| 红点 | 使用炉火橙/暖红，置于“局外成长”“图鉴与档案”右上，不覆盖文字 |
| 弹窗 | 全屏 `#0A1020` 65–75% 遮罩；危险操作默认焦点必须在“取消” |

## 6. 字体建议

- 标题 / 游戏 Logo：可选具有锐利骑士感的中文展示字体，但必须取得商业授权；只用于短标题和 Logo，不作为正文。
- 菜单、数值和正文：优先使用授权清晰、覆盖 GB2312 一级字库的无衬线中文字体，例如 **思源黑体 / Noto Sans CJK SC**；字重建议 Medium 或 Semibold。
- 字号基准：Logo 72–96 px；一级菜单 32–38 px；角色名 30–36 px；战绩数据 22–28 px；说明/版本号 16–20 px。
- 所有菜单标签使用运行时文本渲染，不要写入背景图；为后续多语言保留 30% 横向余量。

## 7. 大厅装饰扩展接口

当前背景可作为 MVP 的稳定底图。后续“大厅装饰”系统应使用独立前景对象或覆盖层，不应直接覆盖或重绘该 PNG：

| 装饰 | 推荐挂点 |
| --- | --- |
| 壁炉 | 中左背景，当前主视觉已有默认炉火；解锁后可切换更亮火焰、附加粒子与音效 |
| 旗帜 | 左侧高窗 / 中景拱门的可替换挂旗层 |
| 地毯 | 展示台至中央拱门的地面路径覆盖层 |
| 灯具 | 中景吊灯与墙灯的独立光源/粒子层 |
| 雕像 | 左侧展示区后景，禁止遮挡角色轮廓 |
| 音乐盒 | 不影响画面；作为大厅 BGM 状态的 UI 与音频逻辑 |
