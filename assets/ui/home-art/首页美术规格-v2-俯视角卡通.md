# 《骑士异闻录》首页美术规格 v2：俯视角 3D 卡通化

## 1. 本次方向修订

首页不采用写实的电影感城堡概念图。游戏采用**俯视角 3D**玩法，因此大厅背景应当让玩家第一眼感受到与实际游戏一致的空间观看方式：高机位、清晰地面、简化形体、可读的轮廓和明快的色块。

| 视角 | 平视电影感大厅 | 约 40–50° 高机位、三分之四俯视 |
| 表现 | 写实材质与高频细节 | 卡通化低多边形轮廓、手绘纹理、Toon 明暗分区 |
| 作用 | 氛围概念候选 | 当前首页与未来 Lobby 的正式候选 |

原 v1 文件不删除，作为风格对照和可回退资产；页面原型已切换到 v2。

## 3. 风格合同

### 必须遵守

- **相机**：高机位三分之四俯视，不得退回平视或横向电影镜头；建议与局内基础相机保持相近的俯视感。
- **形体**：石材、拱门、家具、火炉和展示台使用简化的块面和清晰外轮廓；不堆积现实世界级微细节。
- **材质**：低频手绘纹理、软硬明确的 Toon 阴影、适度边缘高光；避免真实摄影级粗糙度、噪点或湿润反射。
- **可读性**：可从远距离区分展示台、可行走地面、通路和背景装饰；角色叠加后仍能有清晰的轮廓。
- **情绪**：明快、温暖、冒险前的准备感；暖炉火和冷蓝月光形成双主色，但总体不可压抑。

### 必须避免

- 写实照片、虚幻电影概念图、黑暗哥特恐怖和血腥元素。
- 透视过低、强景深模糊、过量雾效、密集粒子或会影响菜单文字的高对比细节。
- 将标题、按钮、数值或角色直接烘焙到背景图中。

## 4. Unity 与首页原型接入

页面背景位于最底层；推荐层级为：

```text
HomeHallBackground (v2 静态底图)
  → AtmosphereFX（少量尘埃、烛火、奥术微粒）
  → CharacterShowcase（左侧实时角色 + 武器 + 接触阴影）
  → UIShade（右侧 25–35% 深蓝渐变）
  → HomeMenuUI（菜单、档案、宝石、战绩）
  → FocusAndModal（焦点框、红点、Toast、确认弹窗）
```

### 导入参数

| 参数 | 建议值 |
| --- | --- |
| Texture Type | Default |
| sRGB | 开启 |
| Wrap Mode | Clamp |
| Filter Mode | Bilinear；若整体采用像素化卡通渲染则改 Point |
| Compression | PC：BC7 高画质；兼容档：BC3 |
| 缩放方式 | Cover；UI 独立锚定，不以背景像素定位 |

## 5. 布局与安全区

基准分辨率为 1920×1080，遵循 SRS P-1。核心 UI 不得进入距四边各 5% 的区域。

| 区域 | 基准比例 | 接入说明 |
| --- | --- | --- |
| 左侧角色区 | 约 45% 宽 | 角色脚底对齐圆形展示台中心；使用实时 3D 待机模型，不将人物画入背景 |
| 右侧菜单区 | 约 35% 宽 | 保留 v2 的暗色负空间；加 25–35% 深蓝遮罩，保证文字对比度 ≥4.5:1 |
| 右下战绩区 | 下方约 20% 高 | 深蓝半透明卡，不压住圆形展示台和中部火炉 |
| 顶栏 | 左右 5% 安全区内 | 档案摘要置左，宝石/版本置右 |

## 7. 后续大厅装饰

所有局外大厅装饰均作为独立前景物体或特效层添加，不能重绘 v2 背景：

- 壁炉：中部火焰亮度、粒子和音效变化。
- 旗帜：高窗和拱门位置的可替换挂旗层。
- 地毯：展示台到中央通路的独立地面覆盖物。
- 灯具：吊灯、墙灯的独立光源与烛火粒子。
- 雕像：左侧后景，不能遮挡角色模型轮廓。
