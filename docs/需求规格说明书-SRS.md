## 1. 引言

### 1.1 编写目的

将 PRD v0.3 的搜打撤产品设计拆解为可开发、可测试、可验收的逐条需求，作为代码开发与测试用例设计的唯一基线。

### 1.2 范围

覆盖 MVP v0.5 至 v1.0 全部功能与非功能需求；v1.1+ 仅占位。

### 1.3 术语

| 术语 | 定义 |
| --- | --- |
| 单局 / Run | 从进入地下城到撤离成功或死亡的完整过程 |
| 小镇 | 安全区枢纽：默认出生点、存档点，无战斗无风险 |
| 层 / Floor | 地下城的一层；每局固定 5 层 |
| 撤离点 | 仅出现在 L2/L4 的交互撤离构造，确认后带出全部物资 |
| 搜索点 | 房间内可交互搜刮的物件，按概率获得物品 |
| 隐藏房 | 需钥匙开启的房间，含高价值搜刮物 |
| 物品实例 | ItemInstance = 物品ID + 档位 + 耐久 + 堆叠数 |
| 装备档位 | 装备阶位：青铜/白银/黄金/钻石/传说（与冒险者等级同名同阶），穿戴需冒险者等级达标 |
| 冒险者等级 | 公会认证等级（青铜→传说），由任务经验驱动；决定任务接取、剧情开放与难度分区 |
| 职业者等级 | 主角成长等级，**每次成功撤离 +1 级**并获得 1 职业技能点，用于小屋技能树加点 |
| 失效 | 装备耐久归零：防具无防御加成；武器无攻击加成且攻击方式变为空手 |
| T1–T5 | 地下城难度分区，分别由冒险者青铜–传说五级解锁 |

## 2. 总体描述

### 2.1 产品功能结构

```
骑士异闻录
├── 核心循环与地下城（小镇/进本/5层结构/搜索点/隐藏房/撤离/死亡/掉落/续局）
├── 战斗与角色（移动/瞄准/攻击方式/翻滚/血蓝/敌AI/精英怪）
├── 物品与装备（物品实例/档位/武器/防具/耐久失效/背包/装备栏/仓库/药剂/卷轴/快捷栏）
├── 小镇建筑（铁匠铺/防具店/药剂店/卷轴屋/杂货铺/冒险者公会）
├── 经济与打造（金币/定价/配方/保养）
├── 任务与成长（任务5类/结算/经验等级/T1–T5解锁）
├── 剧情（章节对话/进度）
├── UI/HUD（HUD/背包/商店/任务板/撤离与死亡结算/暂停设置）
├── 存档（内容/原子写入/死亡删除语义/安全点续局）
└── 音频
```

### 2.2 运行环境与约束

Windows 10/11 64 位；Unity 2022.3 LTS + URP + C#；键鼠为主（手柄预留）；纯单机、无网络通信、无第三方强制运行时依赖（PRD §2.4 Non-Goals）。

## 3. 功能需求（Functional Requirements）

### 3.1 核心循环与地下城

| 编号 | 需求名称 | 优先级 | 需求描述 | 验收标准 |
| --- | --- | --- | --- | --- |
| FR-101 | 小镇安全区 | P0 | 小镇为默认出生点与存档点：无敌人、无掉落风险；6 建筑可交互（§3.4） | 小镇内战斗系统不激活；进入小镇时存档落盘 |
| FR-102 | 进入地下城 | P0 | 小镇入口选择已解锁难度档进入；进本前展示该档怪物强度与掉落档位概览；异步加载 | 点击进本 → L1 首房 ≤ 3s；未解锁档位置灰并显示所需冒险者等级 |
| FR-103 | 5 层结构与层间推进 | P0 | 每局固定 5 层：L1–L3 常规层、L4 撤离层、L5 宝藏层（高价值搜索点密度 ×2、含精英怪）；每层 7–10 房间（v0.2 决议沿用）；每层有下行楼梯口 | **楼层双向回溯**（补全定义）：已访问层之间可往返，保证 L5 取完可返回 L4 撤离，无死局；层间过渡 ≤ 2s；当前层号 HUD 常显 |
| FR-104 | 搜索点 | P0 | 每层 8–15 个搜索点，≥6 种类型 ⚙（木箱/书架/尸骸/宝箱/壁龛/补给袋）；E 交互约 2s，按类型概率表产出，进度可被打断 | 被打断不产出；100 万次抽样概率偏差 ≤ 2%；高价值类型权重随层深递增 |
| FR-105 | 隐藏房与钥匙 | P0 | 每层 0–2 个隐藏房，需钥匙（一次性消耗）开启；内含 2–4 个高价值搜索点 ⚙ | 无钥匙交互提示所需道具；开锁消耗钥匙并有反馈；隐藏房必可达（PCG 校验） |
| FR-106 | 撤离点 | P0 | 撤离点仅出现于 L2、L4（每撤离层 ≥1）；强视觉地标 + 光柱；靠近按 E 弹确认框，确认后**立即撤离（无读条）** | 确认后 ≤ 1s 进入结算；取消确认无副作用；已探索撤离点小地图可见 |
| FR-107 | 死亡与掉落 | P0 | 死亡（HP≤0 或放弃本局）时：胸挂/背包容器内全部物品 + 已装备 8 件（武器/防具×3/胸挂/背包）+ **随身金币**在存档层**物理删除**（彻底消失，不可捡回）；播放物品飞散消散演出 | 死亡后逐项断言：容器/装备/随身金币 = 0；仓库/等级/经验/任务/剧情完好；死亡结算页明示损失清单（名称+数量+档位色） |
| FR-108 | 掉落系统 | P0 | 击杀掉落三类：素材/交易物品/装备；带权掉落表按怪物 × 难度档配置；掉落物带档位光柱，E 拾取入背包 | 100 万次抽样偏差 ≤ 2%；背包满不可拾取并提示；T1 新手保底：前 3 局必出 ≥1 件可用装备 ⚙ |
| FR-109 | 安全点续局 | P1 | 沿用 v1.2 决议：仅在清房、进层、显式返回小镇时快照落盘；主菜单可从最近安全点恢复 | 强退→恢复状态一致；快照在死亡/结算/新开局后清除 |
| FR-110 | 放弃本局 | P0 | Esc 菜单"放弃本局"按死亡处理（物品全删），必须二次确认 | 确认弹窗明示后果；确认后走 FR-107 完整死亡流程 |
