## 1. Executive Summary（项目概述）

### 1.1 问题陈述（Problem Statement）

搜打撤品类（《逃离塔科夫》《Dark and Darker》）验证了"高风险高回报战利品循环"的强吸引力，但现有产品以重度联网 FPS 为主：上手门槛高、挫败感强、单局时间长且无法暂停。**轻量化、单机 PVE、可随时暂停**的搜打撤体验在 PC 市场仍是空档。

### 1.2 解决方案（Proposed Solution）

《骑士异闻录》是一款 3D 俯视角单机 PVE 搜打撤游戏：玩家扮演冒险者，在**冒险者小镇**（安全区）完成补给与整备后进入**随机生成的 5 层地下城**（危险区），通过搜索点搜刮、击杀怪物获取素材/交易物品/装备，抵达第 2 层或第 4 层的**撤离点交互确认撤离**即可带出全部物资；**死亡则身上所有物品（含已装备）彻底消失**。小镇提供铁匠铺/防具店/药剂店/卷轴屋/杂货铺/冒险者公会六大功能建筑，配合装备耐久保养机制、**与冒险者五级同名同阶的装备档位门槛**（青铜→传说），构成"补给 → 冒险 → 撤离/损失 → 再补给"的完整经济循环。

### 1.3 成功标准（Success Criteria）

| # | 指标 | 目标值 | 测量方式 |
| --- | --- | --- | --- |
| K1 | 新手前 3 局内至少完成 1 次成功撤离 | ≥ 60% | 内测埋点（T1 首次进入含引导） |
| K2 | 死亡后回访：单次死亡后 10 分钟内再次进入地下城 | ≥ 70% | 埋点（衡量全掉落惩罚的可接受度） |
| K3 | 性能：GTX 1660 / 1080p / 高画质 | ≥ 60 FPS，战斗场景波动 ≤ 10% | Profiler 基线对比 |
| K4 | 稳定性：单局（20–40 分钟）崩溃 | = 0；存档损坏率 < 0.1% | 自动化压力测试 |
| K5 | 手感：点击→攻击生效输入延迟 | ≤ 100ms；盲测"手感流畅" ≥ 4/5 | 输入埋点 + 问卷 |
| K6 | 内容量（v1.0） | 武器 250 配置项（5 类型 × 5 档 × 10，基础模型 5）/ 防具 375 配置项（5 类型 × 5 档 × 15 = 5 套 × 3 件，基础模型 15）/ 套装 125 个 / 附魔池 ≥10 词条 / **武器技能 10 个（技能树 95 节点）** / 药剂 ≥8 / 卷轴 ≥6 / 素材 ≥15 / 交易物品 ≥15 / 怪物 ≥15 / 任务 ≥30 / 搜索点类型 ≥6 / 剧情章节 ≥3；完整单局（5 层）20–40 分钟 | 内容清单核对（docs/装备清单.md）+ MVP ≥20 有效局实测时长 |

## 2. 用户体验与功能（User Experience & Functionality）

### 2.1 核心循环

```
冒险者小镇（安全区：补给/整备/任务/剧情/存档点）
   │  购买/保养/打造装备，备药剂卷轴钥匙，接任务
   ▼
地下城（危险区：5 层，随机生成，难度按冒险者等级分区 T1–T5）
   │  搜：搜索点概率搜刮 / 钥匙开隐藏房
   │  打：击杀怪物 → 掉落素材 / 交易物品 / 装备
   │  撤：第 2 层、第 4 层设撤离点，交互确认即撤离
   ▼
┌─ 撤离成功：背包 + 已装备物资全部入仓库 → 公会结算任务 → 职业者等级 +1（获 1 技能点）→ 回小镇
└─ 死亡：身上所有物品（含已装备）彻底消失 → 空手回小镇
```

### 2.2 用户画像

| 画像 | 描述 | 核心诉求 |
| --- | --- | --- |
| P1 搜打撤玩家 | 玩过 Tarkov / Dark and Darker | 完整的搜打撤张力，但无需联网与硬核操作门槛 |
| P2 俯视角 ARPG 玩家 | 熟悉《暗黑》类俯视角刷宝 | 装备驱动成长、打造与档位体系 |
| P3 休闲 PC 玩家 | 单局 20–40 分钟、可随时暂停 | 节奏可控、损失可预期（PVE 无玩家偷袭） |

### 2.3 用户故事与验收标准（User Stories & Acceptance Criteria）

**US1 小镇枢纽**
- As a 玩家, I want to 在冒险者小镇自由移动并与 7 处建筑区域交互 so that 完成冒险前的全部整备。
- AC：
  - 小镇为安全区：无战斗、无掉落风险，是默认出生点与存档点；
  - 铁匠铺/防具店/药剂店/卷轴屋/杂货铺/冒险者公会/**冒险者小屋**均可进入并交互，各建筑功能见 US8–US11、US14。

**US2 装备整备**
- As a 玩家, I want to 管理仓库、胸挂/背包容器与装备栏 so that 在负重限制下决定带什么进地下城。
- AC：
  - 仓库物品可自由移入/移出容器；装备栏含武器 1 + 防具 3（头/胸/腿）+ **胸挂 1 + 背包 1**，共 6 位；
  - **所有随身物品仅能存放于胸挂（6 格）与背包（18 格）空间**；容器格满不可拾取；胸挂/背包无耐久概念；
  - **重量系统**：每件物品有重量，负重 = 容器内物品重量之和，**负重越多移速越慢**（阶梯惩罚，超过上限 120% 不可再拾取，详见 SRS §5.12）；
  - 装备穿戴需冒险者等级 ≥ 装备档位对应等级（青铜/白银/黄金/钻石/传说 ↔ 五级），拾取与购买不受限。

**US3 进入地下城（难度分区）**
- As a 玩家, I want to 按冒险者等级选择可进入的地下城难度 so that 风险与收益匹配实力。
- AC：
  - T1–T5 难度分别由青铜–传说五级解锁；高等级玩家可回刷低难度；
  - 进入前展示本难度怪物强度与掉落档位概览；点击进本到进入 L1 首房 ≤ 3 秒（异步加载）。

**US4 地下城搜刮**
- As a 玩家, I want to 搜索房间内的交互点、用钥匙开启隐藏房间 so that 获得战利品。
- AC：
  - 每层 7–10 个房间（沿用 v0.2 决议），房间内分布可交互搜索点（≥6 种类型），交互约 2 秒按概率表获得物品，进度可被打断；
  - 隐藏房每层 0–2 个，需钥匙开启（杂货铺购买，一次性），内含高价值搜刮物；
  - 平面模块拼接（v0.2 决议：不做立体关卡），关键路径满足动态约束（SRS FR-103）。

**US5 战斗与掉落**
- As a 玩家, I want to 用 WASD + 鼠标瞄准战斗 so that 击杀怪物获取掉落。
- AC：
  - 武器提供攻击力加成；**攻击方式/攻击范围/攻速/伤害档由武器类型决定**（刀/骑士剑/长枪/匕首/法杖，差异表见 SRS §5.8），法杖攻击需蓄力（伤害随蓄力时长分低/中/高三档）；武器耐久归零后无攻击加成且攻击方式切换为**空手**；
  - 击杀掉落素材/交易物品/装备三类，走带权掉落表，概率 100 万次抽样与配置偏差 ≤ 2%；
  - 血量/蓝量体系保留（蓝量为后续技能体系预留）。

**US6 撤离**
- As a 玩家, I want to 在第 2 层或第 4 层的撤离点确认撤离 so that 锁定本局收益。
- AC：
  - 撤离点仅出现在 L2 与 L4；L5 为宝藏层（高价值搜刮 + 精英怪），无撤离点，取完需返回 L4 撤离；
  - 靠近撤离点按 E 弹确认框，确认后**立即撤离（无读条）**；
  - 撤离后背包 + 已装备全部入仓库，本局结束进入结算页，任务在此时结算；
  - 撤离结算时，本局带出的每件武器/防具登记**商店解锁**（FR-407）：该物品此后可在铁匠铺/防具店直接购买，未解锁物品不在商店显示；结算页对本次新解锁装备给**显眼提示**（横幅 + 逐件弹报，档位色）。

**US7 死亡惩罚**
- As a 玩家, I want to 清晰知道死亡代价 so that 自主权衡风险。
- AC：
  - 死亡时身上所有物品（背包 + 已装备 + **随身金币**）**彻底消失**（不可捡回，存档层直接删除）；
  - 仓库物资、冒险者等级/经验/任务进度不受影响；
  - 死亡结算页明示本局损失清单，配"物品飞散消散"演出（§2.6 设计红线）。

**US8 铁匠铺与防具店（武器/防具整备）**
- As a 玩家, I want to 购买、保养、打造装备 so that 维持并提升战斗力。
- AC：
  - 铁匠铺：购买武器（基础库存 + **已解锁物品池**）/ 保养武器 / 打造武器；防具店：购买防具（基础库存 + **已解锁物品池**）/ 保养防具 / 打造防具；
  - **撤离解锁**：凡成功撤离带出过的武器/防具，永久上架对应店铺可直接购买（FR-407），售价 = 该物品基准价，武器购买时随机 roll 附魔，未解锁物品不在商店显示；
  - 保养恢复耐久至上限并使**耐久上限递减**（装备是消耗品，形成打造/购买经济循环）；
  - 打造消耗地下城带出的怪物素材 + 金币，产出档位由素材档位决定；传说档装备仅能打造获得；
  - 防具耐久归零 = 无防御加成（装备仍在，可再次保养）。

**US9 药剂店与卷轴屋（消耗品）**
- As a 玩家, I want to 购买药剂和一次性卷轴 so that 地下城内有战术资源。
- AC：药剂店售卖恢复类与增益类药剂（≥8 种）；卷轴屋售卖一次性卷轴（≥6 种，每张仅可使用一次）；两者均可放入消耗品快捷栏（1/2/3）快捷使用。

**US10 杂货铺（卖出与钥匙）**
- As a 玩家, I want to 卖出搜刮物并购买钥匙 so that 变现与解锁隐藏房。
- AC：杂货铺可卖出素材/交易物品/多余装备（卖出价 = 基准价 30%）；钥匙为一次性消耗品，用于地下城隐藏房门。

**US11 冒险者公会（任务/等级/剧情）**
- As a 玩家, I want to 接取任务、结算任务、推进剧情 so that 获得长期成长目标。
- AC：
  - 任务类型：猎杀/搜刮/探索/撤离/制作；任务目标在**撤离成功时**结算，死亡则目标不结算但任务保留；
  - 结算获得金币/经验/物品；经验累积升级：青铜 → 白银 → 黄金 → 钻石 → 传说，等级解锁更高难度（T1–T5）与更高奖励档任务；
  - 每次升级获得属性点用于**局外加点**（FR-605）：本次确认负重属性（每点 +10 负重上限），其余扩展属性待数值评审确定；
  - 剧情以文本对话 + 章节制任务链呈现（≥3 章），无分支结局，进度存档。

**US12 设置与无障碍**（沿用 v0.2 决议：v1.0 设置项锁定）
- AC：画质预设（低/中/高）、主音量/音效/音乐三滑条、全键位重映射、恢复默认、色盲模式预留、镜头缩放（±15%）；设置持久化。

**US13 套装与附魔**
- As a 玩家, I want to 收集防具套装、获取随机附魔武器 so that 追逐毕业装 Build 并保持刷宝动力。
- AC：
  - **套装**（FR-313）：同类型 + 同系别 + 同档位的头/胸/腿 3 件构成套装，集齐激活套装效果（每防具类型 1 种签名效果，数值随档位提升，见 SRS §5.10），拆下任一件即失效；UI 显示集齐进度；
  - **附魔**（FR-314）：武器附魔条数随档位——青铜 0 / 白银 0 / 黄金 1 / 钻石 2 / 传说 3；词条从附魔池（≥10 条）随机 roll，同件武器不重复；roll 时机 = 掉落时、购买时、打造完成时，roll 后固定；
  - **特殊特效**：传说档武器 3 词条 + 全量附魔特效 + 底光流效；钻石档微光特效；词条驱动特效表现（如燃焰 = 火焰缠刃）。

**US14 冒险者小屋**
- As a 玩家, I want to 经营属于自己的冒险者小屋——加点、存放、维修、升级三大区域 so that 拥有一个持续成长的后勤基地。
- AC：
  - 小镇新增冒险者小屋区域（玩家自宅，无 NPC）；
  - **加点**：局外加点面板位于小屋（FR-605），消耗升级获得的属性点分配负重等属性；
  - **存放物品**：小屋接入仓库存取（FR-308），存放占用仓库空间；
  - **小屋升级体系**（FR-507）：三大区域各自独立升级，默认 1 级、满级 5 级、阶梯效果（FR-506/507/§5.13）——**仓库**容量 48→112 格、**锻炼区域**负重上限加成 +0→+50（与加点叠加）、**收藏室**陈列位 8→50；
  - **收藏室陈列**（FR-508）：从仓库将装备入柜陈列，转为展品（不可用不可售、可退回），支持收藏完成度展示（全集 625 件）；
  - **维修装备**（FR-505）：恢复耐久至上限且**不扣耐久上限**、不受保养下限限制，费用约为保养 2 倍——与铁匠铺/防具店的保养形成"便宜伤装备 vs 昂贵保装备"的经济选择。

**US15 职业者等级与技能加点**
- As a 玩家, I want to 每次撤离积累职业者等级并获得技能点，在小屋为战斗/生存/探索加点 so that 把主角养成自己的操作风格并保持长线成长。
- AC：
  - **双等级分离**：冒险者等级 = 公会认证（任务接取、剧情开放、难度分区门槛）；职业者等级 = 主角等级，每次成功撤离 +1 级并获得 1 职业技能点，死亡不涨；
  - **技能加点在小屋进行**（FR-607），每节点消耗 1 技能点，全树 95 点 ≈ 95 次撤离全毕业（核心 Build 约 25–35 局成型）；
  - **战斗**（每武器独立树 10 节点 × 5 = 50 点）：伤害/专精小点 → 解锁**技能 I 与技能 II**（每武器 2 个：旋风斩/斩首姿态、格挡反击/守护之壁、贯穿突刺/横扫千军、影袭/毒刃、奥术洪流/陨星术）→ 大点强化 → **终极被动**（血怒/不屈/破阵/处决者/元素共鸣）；
  - **生存**（6 子线 × 4 点 = 24 点）：体魄/铁骨/轻步/炼金/蓝血/匠心——小点（属性）→ 中点（被动：韧性/再生/脱身/炼金胃/冥想/巧手）→ 大点（强化）；
  - **探索**（13 节点 21 点，仅小节点）：寻宝者/商魂/密室嗅觉/搜刮直觉/矿脉感知/留痕/拾荒者/宝藏猎人/地图师/撤离本能/精打细算/钥匙匠/深入险境。

### 2.4 非目标（Non-Goals）

- ❌ 立体关卡与高度差玩法（沿用 v0.2 决议：v1.1+ 另行评审）

## 3. 程序化生成系统要求（对应 AI System Requirements）

本项目不引入 AI/LLM 功能，核心"智能性"为程序化地牢生成（PCG），结构较 v0.2 收紧为固定 5 层：

### 3.1 生成规则

- **层结构固定**：每局 5 层；L1–L3 常规层（7–10 房/层），L4 撤离层，L5 宝藏层（高价值搜索点密度 ×2、含精英怪）；撤离点仅出现在 L2、L4，每撤离层 ≥ 1 个；
- **房间与路径**：沿用 v0.2 决议——单层 7–10 房间，关键路径房间数 ∈ `[max(5, ceil(roomCount × 0.6)), roomCount]`，关键路径至少含 2 个战斗房；
- **搜索点分布**：每层 8–15 个，类型按层深加权（越深越贵）；隐藏房每层 0–2 个；
- **难度分区**：T1–T5 参数化（怪物属性倍率、素材档位池、掉落权重），生成器按难度档取参。

### 3.2 评测策略（Evaluation）

- 批量生成 1000 座地下城断言：5 层全部连通、L2/L4 必有撤离点且可达、搜索点数量达标、隐藏房可达、无房间重叠；
- Seed 固定与回放，同 Seed 生成结果完全一致；
- 掉落/搜索概率：100 万次抽样与配置偏差 ≤ 2%；
- 压力曲线：L1 前 3 房不得同时出现 > 2 种怪物类型；同屏活跃敌人 ≤ 25。

## 4. 技术规格（Technical Specifications）

### 4.1 架构概览

- **引擎与运行时**：Unity 2022.3 LTS + URP + C#（.NET Standard 2.1）。
- **分层架构**（单向依赖）：①表现层（GameObject/动画/特效/相机，只响应事件）→ ②游戏逻辑层（战斗计算、状态机 AI、物品/背包/耐久、经济、任务、PCG——纯 C# 可单测）→ ③数据层（SO 配置 + JSON 存档）→ ④基础设施层（对象池、事件总线、异步加载、日志断言）。
- **数据流**：配置 SO → 逻辑层实例化 → 事件总线广播（`OnEnemyKilled`/`OnExtractConfirmed` 等）→ 表现层播放；伤害与掉落数值只在逻辑层结算一次。
- **v0.3 新增模块**：
  - 物品与背包系统：统一物品实例（物品ID + 档位 + 耐久 + 堆叠数），背包/仓库/掉落物共用；
  - 装备与耐久系统：装备栏、属性加成计算、磨损/失效/保养规则；
  - 经济系统：金币、商店买卖定价、打造配方校验；
  - 任务系统：状态机（未接取→进行中→可结算→完成）+ 事件驱动目标追踪器；
  - 成长系统：经验/等级/T1–T5 解锁；
  - 剧情系统：章节制对话数据驱动；
  - 存档扩展：仓库/金币/装备/任务/等级/剧情进度；死亡时局内物品在存档层直接删除。

### 4.2 集成点（Integration Points）

| 集成对象 | 方案 | 说明 |
| --- | --- | --- |
| 输入 | Unity Input System | 键鼠为主，Action Map 预留手柄位 |
| 存档 | 本地 JSON + 校验和 | `Application.persistentDataPath`；临时文件 + 原子替换；**安全点快照续局**（v0.2 决议沿用：仅在清房、进层、显式返回小镇时落盘） |

| 版本管理 | Git + Git LFS | 美术二进制资产走 LFS |
| 第三方依赖 | 无强制依赖；DOTween 可选 | 避免重运行时依赖 |

### 4.3 性能预算

- GTX 1660 / 1080p / 高画质：≥ 60 FPS，战斗场景波动 ≤ 10%；
- 单场景 DrawCall ≤ 300、三角面 ≤ 150 万；同屏子弹对象池 ≤ 500；
- 进本加载（点击进本 → L1 首房）≤ 3s；层间过渡 ≤ 2s。

### 4.4 安全与隐私（Security & Privacy）

- 纯单机：无账号、无网络通信、无数据采集上报（崩溃日志仅本地）；存档校验和 + 简单混淆（不以对抗外挂为目标）；不收集未成年人信息。
