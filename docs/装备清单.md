## 1. 数值规则

- **攻击力** = 类型基础攻击 × 档位倍率 × 浮动（0.92~1.08，取整）；DPS = 攻击力 ÷ 攻击间隔（法杖按蓄力，不计 DPS）
- **防御** = 部位基础防御（头 4 / 胸 8 / 腿 6）× 类型防御系数 × 档位倍率 × 浮动（取整）
- **耐久上限**随档位：100 / 130 / 170 / 220 / 300；磨损与保养规则见 SRS §5.3
- **附魔槽位**（FR-314）：青铜 0 / 白银 0 / 黄金 1 / 钻石 2 / 传说 3；词条在掉落/购买/打造时从附魔池随机 roll（见 §5），本清单仅列槽位数
- **套装**（FR-313）：防具按「类型 + 系别 + 档位」构成套装（头/胸/腿 3 件），集齐激活套装效果（见 §4）
- **基准价**：武器 = 攻击力 × 3 + 15；防具 = 防御 × 4 + 15（已含档位成长 → FR-502 实现口径：购买价 = 基准价，卖出价 = 30%）
- **穿戴等级**（FR-312）：档位 ↔ 冒险者同名等级；拾取与购买不受限，仅穿戴受限
